# Contributing to AI Governance Portfolio

Thank you for your interest in contributing!

## How to Contribute

1. **Add Scenarios**: Submit new industry scenarios following the template
2. **Improve Templates**: Suggest enhancements to governance templates
3. **Share Examples**: Contribute completed examples from your organization
4. **Report Issues**: Flag outdated information or framework changes

## Process

1. Fork the repository
2. Create a feature branch: `git checkout -b add-scenario-yourorg`
3. Make your changes
4. Submit a pull request with:
   - Description of changes
   - Reference to issue (if applicable)
   - Links to official framework documentation

## Standards

- Follow existing document formatting
- Map to NIST AI RMF, ISO/IEC 42001, and EU AI Act
- Include all three frameworks in new scenarios
- Add examples when possible
- Keep documents current with framework versions

## Code of Conduct

Be respectful and constructive. This is a collaborative learning resource.
